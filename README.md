## 🎯 The Mission

The **Test de connaissance du français pour le Canada (TCF Canada)** is the premier French language proficiency exam accredited by **Immigration, Refugees and Citizenship Canada (IRCC)**. Scoring at least **NCLC 7** (*Niveau de compétence linguistique canadien*, equivalent to solid European B2) across all four skills unlocks **up to 50 additional Comprehensive Ranking System (CRS) points** under Express Entry, grants eligibility for French-targeted category rounds, and qualifies candidates for the Francophone Mobility Program and provincial nominee streams.

Most commercial courses are either locked behind steep paywalls, emphasize casual conversational tourism, or neglect the computer-based test interface (**TCF-SO**) and face-to-face roleplay examiners (**Expression orale**).

**Zéro French** is built on the proven pedagogical architecture of [The Odin Project](https://www.theodinproject.com/):
1. **Teach Before Linking**: Deep instructional prose (1,500–3,500 words per lesson) explaining grammar inductively through paired patterns before linking to external native resources.
2. **Practice Every Lesson**: Every lesson contains embedded hands-on drills with expandable solutions, Anki flashcard decks, receptive audio/reading tasks, and productive speaking/writing exercises.
3. **Sequential Scaffolding**: Lessons assume only concepts taught earlier in the sequence. No unexplained advanced grammar or vocabulary.
4. **Canadian & International Dual-Track**: Systematic coverage of Québec / Canadian French phonetics (affrication of *t/d*, nasal preservation of */œ̃/*), OQLF administrative terminology (*la facture*, *le stationnement*, *faire l'épicerie*), and winter reality alongside standard international French.
5. **Strict Exam Alignment**: From day one, tasks mirror official France Éducation international (FEI) parameters: timed writing without autocorrect, recorded audio tasks, and 4-criterion FEI rubric grading.
6. **100% Permanently Free**: Zero paywalls, zero trial subscriptions, zero gated content.

## 📚 Path 01: A1 Basics — Inventory (Completed)

Path 01 provides a complete 100-hour foundation across four themed sections:

### Section 1: Foundations & Pronunciation
- [x] **The Alphabet, Accents, and Spelling** — 26 letters, G/J and E/I traps, the 5 accents, postal codes & emails.
- [x] **Pure Vowels, U vs OU, and Nasal Sounds** — Monophthong mechanics, /y/ vs /u/, nasal vowels (/ɑ̃/, /ɔ̃/, /ɛ̃/), Canadian /œ̃/.
- [x] **Silent Letters, Elision, and Liaisons** — CaReFuL rule, elisions, mandatory vs forbidden liaisons, Québec affrication.
- [x] **Numbers, Time, and the Calendar** — 0–100+, vigesimal system (70–99), 12h/24h time, days, months, and dates.
- [x] **Project: Pronunciation Benchmark** — 3-minute oral diagnostic recording auditing phonemes, minimal pairs, and liaisons against FEI benchmarks.

### Section 2: Greetings & Introductions
- [x] **Greetings and Politeness** — Formal *vous* vs informal *tu*, *bonjour* vs *bonsoir*, polite register formulas.
- [x] **Personal Identity and Essential Verbs** — State name, nationality, profession, and age using *être* and *avoir*.
- [x] **Family and Relationships** — Describe family trees, marital status, and possessive adjectives (*mon, ma, mes*).
- [x] **Everyday Objects and Grammatical Gender** — Definite/indefinite articles (*le, la, un, une*), colors, and gender agreement.
- [x] **Project: Introduce Yourself** — 2-minute recorded oral introduction simulating TCF Speaking Task 1 (*Entretien dirigé*).

### Section 3: Daily Routine & Places
- [x] **Regular -er Verbs and Daily Actions** — Present tense *-er* conjugations for morning, work, and evening routines.
- [x] **The Essential Irregular Triad: Aller, Faire, Venir** — Movement, weather, *futur proche* (*aller + inf*), and *passé récent* (*venir de + inf*).
- [x] **Asking Questions and Essential Interrogatives** — Intonation, *est-ce que*, inversion, 7 interrogatives, and the negative contradiction *si*.
- [x] **Places in Town and Navigation Prepositions** — Municipal landmarks, spatial contractions (*du, des, de l'*), *chez* vs *à*, and street directions.
- [x] **Project: Daily Routine & Neighborhood** — Timed 15-minute, unassisted 60–120 word email simulation of TCF Writing Task 1 with FEI rubric.

### Section 4: Food, Shopping & Basic Needs
- [x] **Food, Groceries, and Partitive Articles** — Uncountable nouns, partitives (*du, de la, des*), preference verbs, and negative *de*.
- [x] **Ordering at a Café and Polite Transactions** — Counter orders, conditional of politeness (*je voudrais*), prices, bills, and Canadian tipping.
- [x] **Clothing, Sizes, and Adjective Agreements** — Everyday garments, BANGS adjective placement, invariable colors (*marron, orange*), Canadian winter gear.
- [x] **Weather, Seasons, and Temperatures** — Impersonal *faire*, precipitation verbs, sub-zero Celsius, wind chill, and season prepositions.
- [x] **Project: A1 Capstone Challenge** — Integrated 3-minute TCF Speaking Task 2 roleplay inquiry and timed 60–80 word TCF Writing Task 1 email with calibrated AI self-assessment prompts.

## 🛠️ Local Development & Running

Zéro French runs as a zero-dependency, no-build static web application using vanilla HTML5, CSS3, and JavaScript.

### 1. Clone the Repository
```bash
git clone https://github.com/espiNovah/zero-french.git
cd zero-french
```

### 2. Launch Local Server
You can serve the directory using Python's built-in HTTP server or any static file server:

```bash
# Using Python 3
python3 -m http.server 8080

# Or using Node.js npx
npx serve .
```

Open your browser to `http://localhost:8080/`.

### 3. Curriculum Validation
Validate the markdown structure, heading levels, and anchor links:

```bash
python3 scripts/validate.py
```

Test all external resource URLs across the curriculum:

```bash
python3 scripts/validate.py --links
```
